# /stend — локальный стенд

Стенд — копия продукта на маке Милы: Postgres в Docker, веб, бот, воркер и тридцать придуманных
участниц. Настоящих данных здесь нет и не будет (`CLAUDE.md`, правило 1).

## Два режима

| Режим | Команда | Telegram | Для чего |
|---|---|---|---|
| работа | `scripts/dev-stack.sh up` | поддельный, `http://127.0.0.1:8081` | автотесты, критики, скриншоты, макеты переписки |
| живой | `scripts/dev-stack.sh up --live` | настоящий, через тестового бота | проверка глазами в Telegram перед релизом |

В обоих режимах данные одни — демо-набор. В «живом» режиме бот отвечает только тем, кто ему
напишет; демо-участницы для настоящего Telegram не существуют, поэтому написать реальному
человеку он не может.

## Порядок

1. **Docker запущен?** `docker info >/dev/null 2>&1 || echo "Docker не запущен"` — если нет,
   попроси Милу открыть Docker Desktop и подожди.
2. **Поднять.** `scripts/dev-stack.sh up` (или `up --live`). Скрипт сам: стартует Postgres,
   накатывает миграции, заливает сезон и демо-данные (если база пустая), запускает сервисы,
   проверяет `/healthz`. В живом режиме — читает токен из `.dev/dev-bot.env` (нет файла → скажи
   Миле открыть `docs/SETUP-RU.md`, раздел «Тестовый бот»), проверяет доступ к Telegram и при
   отказе говорит: «Telegram не отвечает — включи VPN».
3. **Проверить глазами.** `curl -s http://127.0.0.1:8010/healthz` → `"status":"ok"`.
   `tail -n 20 .dev/logs/bot.log` — нет ошибок.
4. **Ссылка для Милы.** `scripts/dev-stack.sh link admin` — админка (в режиме «работа» это
   900001, в живом — её настоящий Telegram-номер из `.dev/dev-bot.env`; другой id админом не
   будет); `scripts/dev-stack.sh link 1001 Алиса /app` — приложение участницы. Команда печатает
   две строки: Миле отдавай первую (ссылка для браузера), вторая — служебный заголовок для API.
5. **Логи.** `scripts/dev-stack.sh logs` (все) или `.dev/logs/{bot,web,worker,telegram}.log`.
6. **Пересоздать с нуля.** `scripts/dev-stack.sh reset` — удаляет ТОЛЬКО контейнер стенда и
   `.dev/media`, заливает демо-данные заново. К проду отношения не имеет.
7. **Погасить.** `scripts/dev-stack.sh down`.

## Что сказать Миле

Коротко: стенд поднят в таком-то режиме, вот ссылка на админку и на приложение, вот что можно
потыкать; если живой режим — «напиши тестовому боту @<имя> в Telegram /start». Не перечисляй
внутренности (порты, контейнеры), если она не спросила.

## Если не поднимается

- «port already in use» — старый стенд жив: `scripts/dev-stack.sh down`, затем `up`.
- Postgres не отвечает 30 с — Docker только что запустился, повтори `up`.
- Живой режим: `409 Conflict` — этот же токен крутится где-то ещё; `getMe` не отвечает — VPN.
- Что-то другое — `.dev/logs/*.log`, и не гадай: приведи Миле строку ошибки и что она значит.
