# /status — где мы

Сессия начинается отсюда: контекст живёт в файлах, не в памяти чата.

1. `git fetch origin -q; git status -sb; git branch --show-current` — ветка, незакоммиченное,
   отставание от `origin`.
2. `python3 scripts/brain_index.py && cat brain/backlog.md` — задачи по состояниям.
3. Для задач не в `closed`/`on_prod` — последние три строки журнала из их `status.md`.
4. Незакоммиченные изменения → скажи, к какой задаче они относятся (по ветке), не трогай.
5. `ls brain/ops | tail -1` — когда последний снимок прода; старше недели — предложи `/prod`.

Миле — по-русски, пять-семь строк, без служебных слов:
- над чем работаем сейчас и в каком оно состоянии;
- что ждёт её ответа (план прочитать? «ок» на dev? «выкатываем»?) — с командой `open …`;
- что следующий шаг, одной фразой;
- если ничего не открыто — «всё закрыто, можно брать новое: расскажи, что хочется».
