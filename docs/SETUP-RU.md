# Разовая настройка: GitHub, мак, стенд, бэкапы

Это делается один раз. Дальше живём по `docs/GUIDE-RU.md`. Почти всё ниже можно не делать
руками: открой репозиторий в Claude Code и попроси «сделай разовую настройку по
docs/SETUP-RU.md» — Claude пройдёт шаги сам и скажет, где нужна ты (GitHub, VPN, Docker).
Займёт минут двадцать плюс два коротких ожидания Димы.

## 1. GitHub: закрыть репозиторий

Сейчас репозиторий открыт всему интернету, а папка `docs/` ещё и раздаётся как сайт. Закрыть
может только владелица, то есть ты, в браузере:

1. Открой `github.com/milanosova/romantika-marshrutov` → **Settings** (вкладка справа).
2. Вкладка **Pages** (слева) → **Source** → выбрать **None** → Save. Сайт из `docs/` выключится.
3. Вкладка **General** → самый низ, красная зона **Danger Zone** → **Change repository
   visibility** → **Make private** → подтвердить, набрав имя репозитория.
4. Вкладка **Collaborators** → убедиться, что `konductor000` (Дима) в списке. Если нет —
   **Add people**.

Проверка: открой репозиторий в приватном окне браузера — должно быть «404».

## 2. Мак: что должно стоять

Открой Terminal (⌘ + пробел, набери Terminal) и вставляй по одной строке. Если Claude Code уже
установлен и открывает этот репозиторий — пункты про него пропусти.

```
# Homebrew — установщик всего остального (спросит пароль от мака)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# инструменты: git, uv (Python), pango и libpq (для PDF и проверки бэкапов), Docker Desktop
brew install git uv pango libpq
brew install --cask docker
```

Открой **Docker Desktop** из папки Программы один раз: он попросит разрешения и запустится в
фоне (значок кита в строке меню). Docker нужен для стенда и для тестов; если кит не горит —
стенд не поднимется, Claude так и скажет.

Google Chrome нужен для скриншотов в отчётах (обычный Chrome, установленный как программа).

## 3. Репозиторий на маке

```
cd ~
git clone https://github.com/milanosova/romantika-marshrutov.git
cd romantika-marshrutov
uv sync
cp .env.example .env
```

Файл `.env` для стенда менять не нужно (стенд задаёт всё сам); он нужен только тестам.
Проверка, что всё стоит: `make check` — минуты две, в конце «passed» и ни одного «failed».
Первый раз Docker скачает образ Postgres — это нормально.

## 4. Доступ к серверу (ключ)

Уже сделано, если Дима сказал «добавил» после раздела «Доступ Claude к серверу» в
`docs/GUIDE-RU.md`. Проверка в терминале:

```
ssh romantika-vps 'docker ps --format "{{.Names}}"'
```

Должны напечататься контейнеры `romantika-…`. Ошибка «Permission denied» — ключ не добавлен
или файл `~/.ssh/config` без блока `Host romantika-vps`: вернись к тому разделу.

## 5. Тестовый бот

Для проверок в настоящем Telegram есть отдельный бот `@romantika_staging_bot`. Его токен (пароль
бота) Дима положил на сервер в твою домашнюю папку; в переписке и в репозитории токен не
появляется никогда.

```
mkdir -p .dev
scp romantika-vps:/home/romantika/dev-bot.env .dev/dev-bot.env
chmod 600 .dev/dev-bot.env
```

Файл `.dev/dev-bot.env` живёт только на твоём маке (папка `.dev` не попадает в git). В нём
`BOT_TOKEN`, `BOT_USERNAME` и `ADMIN_IDS` — твой и Димин Telegram-номера, чтобы в тестовом боте
у вас была панель админа.

## 6. Первый запуск стенда

Стенд — копия бота и приложения на твоём маке с тридцатью придуманными участницами. Настоящих
данных на нём нет и не будет.

В Claude Code: «подними стенд». Или в терминале: `scripts/dev-stack.sh up`. Через несколько
секунд Claude даст две ссылки — админка и приложение участницы — открой их в обычном
браузере. Если хочешь пощёлкать сама: `scripts/dev-stack.sh link 900001 Мила /app/admin`.

Живой режим (бот в настоящем Telegram): включи VPN, затем «подними стенд в живом режиме»
(`scripts/dev-stack.sh up --live`). Найди в Telegram `@romantika_staging_bot`, напиши `/start`
— это твой стенд отвечает. Приложение в живом режиме открывается по ссылке из `link` в
браузере, а не из кнопки бота: кнопка бота ведёт на настоящий сервер.

Погасить: «погаси стенд» или `scripts/dev-stack.sh down`.

## 7. Бэкапы на твой мак

Каждую ночь сервер делает копию базы и всех фото. Чтобы вторая копия жила у тебя:

```
scripts/install-mac-pull.sh
scripts/mac-pull-backups.sh
```

Первая команда ставит задание «каждое утро в 9:15 забрать копию», вторая забирает прямо
сейчас. Копии лежат в `~/Backups/romantika/`. Мак ночью может быть закрыт — тогда копия
приедет, когда ты его откроешь. Если у Димы тоже стоит копия — их две, это хорошо.

## 8. Проверка, что всё вместе работает

В Claude Code: «что у нас» (`/status`). Claude должен ответить, что открытых задач нет или
назвать их, и предложить следующий шаг. Потом «как дела у бота» (`/prod`) — снимок настоящего
сервера: жив ли бот, сколько человек за сутки, всё ли с бэкапами.

Если что-то из этого не получилось — не чини сама, напиши Диме, что именно написал Claude.

## Если сменился мак

Повтори разделы 2–7. Ключ к серверу (раздел 4) придётся создать заново и снова отправить
Диме открытую половинку — это описано в `docs/GUIDE-RU.md`.
