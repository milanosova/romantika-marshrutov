# 05 · Правки 19 сентября

Мила посмотрела выкаченную 2.5.0 и назвала список правок голосом. Плана по её просьбе нет
(как в задаче 04): ответы на три вопроса получены кнопками — имена недель «Неделя antojo

## Приёмка

- [x] «Сезон»: название сезона крупно терракотовым, как на «Неделе»
- [x] Шапка «Недели»: «Неделя 3 из 12 · дедлайн задания до воскресенья, 18:00»
- [x] Карточка дня майя — четыре строки: «день по календарю майя» / «6 Ахав · владыка» /
      толкование / «Узнай своё предназначение →» вместо «Календарь →»
- [x] Заголовок задания — название недели без номера перед ним
- [x] Имя недели пишется в админке так, как в канале («Неделя rola [музыка]»); экраны,
      которые сами печатают номер, слово «Неделя» не повторяют: бот «Неделя 3 · rola
      [музыка]», паспорт «3. rola [музыка]», летопись, журнал, PDF, админка
- [x] Первый свой факт даёт +1 заморозку: форма обещает, лист заморозок называет, бот и
      приложение отвечают, плитка заморозок обновляется; второй факт — не даёт; факт Милы —
      не даёт (её факты общие)
- [x] «Что будет в конце сезона»: без женского рода («твой отчёт, слово в слово») и без
      привязки к ноябрю
- [x] DOMAIN §3 и §7, GUIDE-RU, ARCHITECTURE, CHANGELOG v2.6.0; `make check` зелёный

## Чего не трогаем

- Данные стенда (`data/seasons/mexico-2026.json`): названия недель там пинят приёмочные
  тесты Димы (правило 5). Имена недель — контент админки, Мила меняет их на проде сама.
- Правила штампов, поздних отчётов, напоминаний, личных слов и фактов — из задач 03 и 04.
- Потолок заморозок за сезон (5) не поднимали — см. журнал.
