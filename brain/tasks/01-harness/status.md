# 01 · Харнес для работы Милы через Claude Code

Кто увидит и где: Мила — в Claude Code (команды, планы и отчёты), Дима — в репозитории.
Участницы не видят ничего: код бота не меняется.

## Приёмка

- [ ] Claude называет маршрут первой фразой на любую просьбу (контент / микро-правка / фича / авария)
- [ ] Восемь скиллов на месте, подхватываются по русским фразам без знания команд
- [ ] Стенд поднимается одной командой в режиме «работа» с тридцатью демо-участницами и в живом режиме с тестовым ботом
- [ ] Скриншоты экранов и макеты переписки собираются скриптами в папку задачи
- [ ] Карточки задач и `backlog.md` ведутся автоматически, `/status` пересказывает состояние
- [ ] `make check` зелёный; приёмочные тесты проверяют харнес и запрещают кириллицу в коде
- [ ] Гайд разовой настройки для Милы (`docs/SETUP-RU.md`) и переписанный `GUIDE-RU.md`

## Чего не трогаем

- Код бота, приложения и воркера (кроме новых модулей в `romantika/ops/`)
- Прод: выкатка не требуется, харнес живёт в репозитории и на маке Милы
- Хуки, песочница, перехватчики команд — не заводим (решение владельца 2026-09-16)
