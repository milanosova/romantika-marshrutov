# В карточке человека у Милы «text/photo» вместо «текст/фото»

Найден 2026-09-18 критиком поверхности при `/relize` v2.3.0. Не из этого релиза: админка в
диффе не менялась.

**Симптом.** Админка → «Люди» → карточка участницы → блок «Отчёты (N)»: строки вида
«Неделя 3 · 18.09 13:04 · ✅ text», «⭐ photo». У участницы в приложении то же место
по-русски («✅ минимум · текст»). Скриншот стенда: `.dev/shots/rel-flows/admin-person-card.png`
(не в git).

Рядом: `GET /api/admin/participants/{id}` отдаёт `week_intent: null, week_level: null,
week_reports: 0`, хотя список `GET /api/admin/participants` у того же человека даёт
настоящие значения. На экране эти поля не рисуются — вреда нет, но поля мёртвые.

**Что предлагаю.** В `admin.js` брать подпись вида отчёта из `texts` (как `kindName` в
`app.js`); в `views.participant_detail` либо заполнять три поля, либо убрать их из схемы.
Микро-правка.
