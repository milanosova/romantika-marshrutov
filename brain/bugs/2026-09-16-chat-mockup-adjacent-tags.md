# Макет переписки портит числа между двумя тегами подряд

Найден 2026-09-16 при снятии «было» для задачи 02 (`/zadacha`). На проде и в боте не виден:
ломается только инструмент, который рисует макеты переписки для планов и отчётов Милы.

**Симптом.** `uv run python -m romantika.ops.chat_mockup --scenario passport --user 1001`
рисует в паспорте строку «Штампов: 45 из 12 · со звёздочкой: 2». В приложении у той же
участницы — «2 / 12», и список недель в самом макете показывает два штампа. То есть макет
показывает Миле число, которого нет.

В сохранённом HTML (`brain/tasks/02-passport-join-date/before/chat-passport.html`) на этом
месте лежит `Штампов: \x004<b>5\x00 из 12` — два нулевых байта и незакрытый `<b>`.

**Причина.** `romantika/ops/chat_mockup.py:72` в `_clean()`:

```python
key = f"\x00{len(keep)}\x00"
```

Теги бота прячутся под метки `\x00N\x00`, а потом возвращаются подряд циклом
`escaped.replace(key, tag)` для N = 0, 1, 2, … Когда теги стоят вплотную к короткому тексту
(`<b>2</b>` → `\x0010\x002\x0011\x00`), хвостовой `\x00` первой метки, сам текст «2» и головной
`\x00` второй метки складываются в метку `\x002\x00` — метку тега номер 2. Цикл доходит до неё
раньше настоящих меток 10 и 11 и подставляет туда чужой тег. Число участницы исчезает, номера
меток («10», «11») вылезают в текст как цифры. Нужно ≥ 3 теги до этого места, поэтому короткие
сценарии (`start`) целы, а паспорт — нет.

Воспроизводится в одну строку:

```
uv run python -c "from romantika.ops.chat_mockup import _clean; \
print(repr(_clean('<b>A</b>\n<b>B</b>\n<b>C</b>\n<b>D</b>\n<b>E</b>\nШтампов: <b>2</b> из 12')))"
# ... 'Штампов: \x0010<b>11\x00 из 12'
```

**Чем починить** (не сделано, ждёт задачи 02). Возвращать теги одним проходом регулярным
выражением, а не серией `replace`: проход слева направо съедает метку целиком и не может
собрать метку из хвостов двух соседних.

```python
escaped = re.sub("\x00(\\d+)\x00", lambda m: keep_by_index[int(m.group(1))], escaped)
```

**Как не повторить.** Тест на `_clean()` с тремя парами тегов и коротким числом между ними, и
проверка, что в готовом макете нет байта `\x00`. Обе проверки — в `tests/` вместе с правкой.

**Почему это важно.** Макеты переписки — то, по чему Мила утверждает планы и принимает работу
(`/zadacha` шаг 3, `/otchet`). Инструмент, который тихо меняет числа, обесценивает её «ок».

**Починено 2026-09-16** (ветка `harness`): разделители стали `\x00N\x01` (два разных управляющих
символа — из хвоста одного ключа, цифры и головы следующего такой ключ не собрать), обратная
замена — одной проходкой регулярного выражения `SENTINEL_RE`. Регрессионный тест —
`tests/unit/test_chat_mockup.py::test_clean_survives_digits_between_many_tags`. Макет паспорта
на стенде теперь показывает «Штампов: 2 из 12».
