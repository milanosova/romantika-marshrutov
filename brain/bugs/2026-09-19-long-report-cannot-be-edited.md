# Длинный отчёт из бота нельзя поправить

Найден 2026-09-19 критиком поверхности при проверке задачи 06.

**Симптом.** Бот принимает отчёт любой длины (Telegram отдаёт до 4096 знаков), приложение
режет на 4000. Участница присылает в чат 4050 знаков → отчёт записан → открывает «Рюкзак» →
«✏️ Поправить» → правит букву → «Сохранить» → `PATCH /api/reports/{id}` → 422, тост «Не
сохранилось: текст длиннее 4000 знаков». Сохранить можно только урезав свой же текст.

**Почему важно сейчас.** С 19.09 (задача 06) форма на вкладке «Неделя» прямо посылает в этот
журнал: «Отчёты этой недели — в «Рюкзаке», в журнале: там их правят». Для длинного отчёта
обещание не выполняется.

**Что сделать.** Поднять предел правки до 4096 (столько же, сколько принимает бот), либо
резать в боте на 4000 при приёме — но тогда часть текста пропадёт, что хуже. Проверить заодно
`TextIn` и лимит в `reports.accept`.
