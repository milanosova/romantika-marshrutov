# В черновике «Привала» голая строка у того, кому штамп поставлен руками

Найден 2026-09-18 критиком поверхности при `/relize` v2.4.0. Не из релиза: сводка и
ручные штампы не менялись.

**Симптом.** Мила ставит штамп руками («Люди» → карточка → «⭐ Максимум») человеку, у
которого за неделю нет отчёта → в черновике «Привала» строка `⭐ Катя` без « — цитаты».
`GET /api/admin/summary?week=1` → `draft_post` содержит `'⭐ Катя'`.

**Причина.** `summary._quotes` берёт первую строку текста отчёта; при ручном штампе
отчёта нет — цитаты нет, а строка печатается.

**Что предлагаю.** В черновике — `⭐ Катя — (допиши)` или не печатать строку без цитаты
(штамп руками обычно за комментарий в канале, слова там уже есть). Микро-правка после
решения Милы.
