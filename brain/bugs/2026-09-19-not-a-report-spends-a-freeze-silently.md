# «Это не отчёт» на прошедшей неделе тратит заморозку молча

Найден 2026-09-19 критиком поверхности при проверке задачи 06.

**Симптом** (участница 1022, неделя 1 из трёх со штампами):
```
до:    штампов 3, цепочка 3, лучшая 3, заморозок 3 из 3, потрачено 0
после: штампов 2, цепочка 2, лучшая 2, заморозок 2 из 3, потрачено 1, неделя 1 → «заморожена»
```
Подтверждение говорит: «Штамп за неделю пересчитается, а текст останется у меня как обычное
сообщение». Про заморозку и про лучшую цепочку — ни слова ни в подтверждении, ни в ответе.

**Почему важно.** С 19.09 журнал в «Рюкзаке» — единственное место, где отчёты правят и
отменяют (блок «Мои отчёты» с вкладки «Неделя» убран), так что кнопка теперь на главном
маршруте.

**Что сделать.** В подтверждении для прошедшей недели сказать цену: «Неделя станет
пропущенной — на неё уйдёт одна заморозка». Для текущей недели цены нет, там текст верный.
Пересчёт менять не нужно — он по правилу (DOMAIN §3).
