title: Mini App из кнопки тестового бота в живом режиме стенда
status: idea
created: 2026-09-16
---

Сейчас в живом режиме стенда (`scripts/dev-stack.sh up --live`) бот работает в настоящем
Telegram, а приложение открывается только по подписанной ссылке в браузере: кнопка меню бота
ведёт на настоящий сервер, и тот отвергает подпись тестового бота.

Чтобы приложение открывалось прямо из Telegram на стенде, нужен публичный https-адрес мака.
Вариант: `cloudflared tunnel --url http://127.0.0.1:8010` (quick tunnel, случайный адрес на
trycloudflare.com), затем `romantika.ops.telegram_setup` с `PUBLIC_BASE_URL` = адрес туннеля
для тестового бота. Cloudflared ставится через `brew install cloudflared`. Не делаем, пока
живой прогон бота в Telegram плюс приложение в браузере покрывают потребность.
