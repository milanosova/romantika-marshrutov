## Как устроен сезон

Двенадцать недель. Каждый понедельник выходит задание: **минимум** на пять минут и **максимум** на вечер, оба необязательные. В воскресенье — итоги с именами тех, кто сделал.

За выполненную неделю человек получает штамп в паспорт сезона. Пропущенная неделя тратит **заморозку** — их две базовых плюс до трёх заработанных, и цепочка от пропуска не рвётся. К финалу каждый участник получает свой журнал: его недели его же словами, фотографии, ачивки, словарь.

Первый сезон — Мексика, 18.08 — 18.11.2026.

## Сохранить изменения

Всё делается из этой папки:

```
cd "/Users/milanabelonosova/Посты в тг. Романтика маршрутов"
```

**Посмотреть, что изменилось** — необязательно, но полезно:

```
git status
```

**Сохранить и отправить** — три команды:

```
git add -A
git commit -m "коротко, что поменяла"
git push
```

`add` собирает изменения, `commit` записывает их в историю с подписью, `push` отправляет на GitHub. Пока не сделан `push`, изменения только на маке.

Секреты не попадут даже случайно: `.gitignore` их не пускает.

**Если что-то сломала и хочешь вернуть как было:**

```
git checkout -- .
```

Отменяет все несохранённые правки. То, что уже закоммичено, не тронет.
